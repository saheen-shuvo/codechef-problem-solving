# CodeChef Problem Solving

This repository contains C++ solutions to various CodeChef programming problems.  
Each `.cpp` file is a standalone solution for a specific problem.

## Repository Structure

- `*.cpp` — individual problem solutions
- `.cph/` — helper/problem metadata generated by Competitive Programming Helper tools
- `.vscode/` — local editor settings

## Requirements

- C++ compiler with C++17 support (e.g., `g++`)

## Compile and Run

Use any solution file independently.

```bash
g++ -std=c++17 -O2 -o solution Problem_Name.cpp
./solution
```

## Notes

- Most programs follow the competitive programming input format (`T` test cases first when required).
- No single combined build/test pipeline is configured; run solutions file-by-file.
